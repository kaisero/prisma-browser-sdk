# prisma-browser-sdk

Python SDK for the Palo Alto Networks Prisma Browser

> Generated by [phantasos](https://github.com/kaisero/phantasos). Do not hand-edit — changes
> are made upstream in the phantasos product definition and regenerated.

## Install

```bash
pip install prisma-browser-sdk
```

## Usage

```python
from prisma_browser.extras.facade import Client

client = Client.from_env()
```

See [https://github.com/kaisero/prisma-browser-sdk](https://github.com/kaisero/prisma-browser-sdk) for full documentation.
